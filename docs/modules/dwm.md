# DWM module

Portable **X11** session wrapper for `--desktop dwm`. Does not start Niri or Waybar. Bar is **slstatus** (plus picom).

The dump under `.config/dwm/` (C sources, xrandr host scripts) stays in place. This module only plans `~/.config/dwm/xinitrc`.

## Dry-run

```bash
./install.sh --dry-run --desktop dwm
```
