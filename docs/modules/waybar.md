# Waybar module

Portable Waybar for **`--desktop plasma` only** (KDE Wayland visual bar). Never planned with `--desktop niri` (Noctalia) or `--desktop dwm` (slstatus).

New generic `config.jsonc` / `style.css`. Dump `config-dp1.jsonc` and host outputs stay in `.config/waybar/`.

## Dry-run

```bash
./install.sh --dry-run --desktop plasma
```
